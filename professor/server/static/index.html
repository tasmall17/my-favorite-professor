One thing before you start

This app runs on your own Anthropic key, so your material and your questions go straight from your machine to Anthropic — nothing routes through anyone else. You'll only do this once.

  1. 1

    Open the Anthropic console and sign in.

    console.anthropic.com/settings/keys ↗
  2. 2

    Click Create Key, name it something like my-favorite-professor, and copy it.

    It's shown once. If you lose it, make another.

  3. 3

    Paste it here.

Stored at ~/.config/my-favorite-professor/config.json, mode 0600, read only by this server. It's never sent to the browser and never leaves your machine except to Anthropic.
